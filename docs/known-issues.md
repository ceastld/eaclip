# 已知问题

按 0.31.26 整理。来源：各版本发布说明里的修复与已知限制、[反馈仓库](https://github.com/QuickerHub/cea-action-issues/issues) 的 issue、程序代码中的行为约束。"已修复"的条目请先确认用户版本。

## 当前版本（0.31.x）的已知限制

### 安全软件与签名

- 程序**尚未配置可信发布者代码签名**，部分安全软件可能告警。0.31.15 起已去掉跨进程加载 DLL 等容易被误报的做法，但尚未取得卡巴斯基复测确认。建议只从 [eaclip Releases](https://github.com/ceastld/eaclip/releases) 或「剪贴板 n10」获取，并核对 SHA-256。

### ARM64

- 文件对话框（打开 / 另存为）的部分原生增强目前只有 x64 实现。
- 完整的 Quicker 桌面流程、中文输入法、OLE 拖放和第三方应用回贴在 ARM64 上尚未逐项实机验证（0.31.24 说明仍注明"ARM64 第三方应用回贴未由检查替代"）。

### 局域网与设备同步

- 0.31.26 起，**设置 → 设备同步** 提供默认开启的总开关及文本 / 图片选择；此前明确关闭的总开关会保留。设备仍须先配对，暂停使用总开关控制。
- 已验证两台 Windows 的文本 / 图片收发、内容选择、暂停恢复，以及模拟第三方重新编码同图后的精确去重与无回声；**真实微信客户端并存、三台以上设备、锁屏 / 睡眠 / 断线**等场景仍未完整验证。
- 像素完全相同、仅 PNG 编码或标准附加信息不同的图片可复用条目；第三方确实改变图片内容时仍会产生新内容，同时开启多款同步工具仍可能互相影响。
- 文件不自动同步，只能手动互传。
- 找不到设备多半是不在同一局域网、对方没开互传，或 Windows 防火墙拦截。
- 手机同步未开放。

### 输入、拖放与显示

- 物理中文输入法、OLE 拖放、跨显示器拖动等场景的完整桌面验收仍有边界，个别环境可能表现不一致。
- 0.31.14 修正了显示器断连 / 恢复时隐藏窗口被错误显示的问题；"息屏后主屏点击异常"的现场复验当时仍在进行，未宣布完全解决。
- 0.31.17 降低了显卡驱动重置、显示器恢复时的崩溃风险；有用户反馈的"进程自行退出"**根因尚未确定**，0.31.17 起加入了退出诊断记录，再次发生时请收集诊断。

### 行为上的约束（不是 bug）

- 便携版与安装版不能同时运行（同一用户只允许一个实例），两者共用同一份数据。
- 修改数据文件夹**不会自动迁移数据**。
- 调低"记录历史条目上限"时，确认后会**永久删除**超出的非置顶历史。
- 使用 Win+V 打开剪贴板需要重启 Windows 资源管理器才生效 / 才恢复。
- 菜单或弹层打开时，以及搜索框里已有内容时，数字键不会粘贴（数字会进入搜索或被暂停）。
- 用 `Ctrl` + `F` 进入正常焦点模式后，CapsLock 引导键暂不可用，关闭窗口再打开即可恢复。
- 普通文件和多文件记录只保存路径，原文件被删除或移动后该记录无法使用；只有截图软件等已知临时图片会另存（0.31.24 起）。
- 暂停记录是开关，不能按时长暂停。
- 新的存储格式仍在隔离验证，正式版不会自动切换。

## 旧版（0.30.x）问题

0.30.x 是旧的 .NET + WebView 版 ClipHost（「剪贴板 n10」早期版本，进程名 `IntelliTools.ClipHost`），已被 0.31.x 取代、不再修复。以下问题如果用户仍在 0.30.x，**建议直接升级到 0.31.x**：

- 0.30.35 发布包缺少 `IntelliTools.Quicker.dll`，报 `FileLoadException`（HRESULT `0x80131047`），子程序无法加载——0.30.36 已修复。
- 打开后窗口全黑（0.30.32，双显卡 / 4K 环境，[#83](https://github.com/QuickerHub/cea-action-issues/issues/83)）——WebView 渲染问题，0.31.x 已不使用 WebView。
- 后台空闲 CPU 约 8–10%（[#84](https://github.com/QuickerHub/cea-action-issues/issues/84)）。
- 选中文字时鼠标丢帧卡顿（[#103](https://github.com/QuickerHub/cea-action-issues/issues/103)）。
- 剪贴板卡顿连带 Quicker 卡顿 / 泛白、拖慢企业微信滚动等钩子相关问题（[#90](https://github.com/QuickerHub/cea-action-issues/issues/90)、[#92](https://github.com/QuickerHub/cea-action-issues/issues/92)）。
- 「剪贴板改变时触发自定义动作」填组合动作时在 Quicker V2 下报 MissingActionContext（[#76](https://github.com/QuickerHub/cea-action-issues/issues/76)）。

> 待确认：上述 0.30.x 问题在 0.31.x 中是否都已不再出现（多数源于 WebView / .NET 宿主，但未逐项复测）。
