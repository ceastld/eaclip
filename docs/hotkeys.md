# 快捷键

下文 "`` ` ``" 指主键盘 Esc 下方的反引号键（Windows 键名 `Oem3`）。本页按当前源码核对；**没有列出的按键就不要假定存在**。0.32.0 补齐历史列表 `Ctrl+A`、无焦点 `Ctrl+C` / `Ctrl+P` 及 Enter 多选顺序粘贴。

## 全局快捷键（默认值）

在任意应用中可用，需要 ClipHost 在运行。

| 默认快捷键 | 作用 | 修改位置 |
| --- | --- | --- |
| `Ctrl` + `` ` `` | 显示 / 隐藏剪贴板窗口 | 设置 → 触发 → 显示/隐藏剪贴板窗口 |
| `Ctrl` + `Shift` + `` ` `` | 显示 / 隐藏收藏面板 | 设置 → 触发 → 收藏面板 |
| `Alt` + `` ` `` | 便捷粘贴：**按住**弹出最近剪贴板预览，滚轮或方向键切换，**松开**即粘贴选中项 | 设置 → 便捷粘贴 → 便捷粘贴 |
| `Win` + `` ` `` | 打开超级菜单（窗口、文件、收藏、书签、文本、剪贴板），不需要先打开剪贴板窗口，也不依赖 Quicker | 设置 → 触发 → 打开超级菜单 |

- 每项留空表示禁用。
- 组合键冲突时设置页会给出提示；例如便捷粘贴与"显示/隐藏剪贴板窗口"设成同一组合时，便捷粘贴不会生效。
- 聚合搜索（0.31.24）没有默认全局快捷键，见 [使用说明](usage.md#聚合搜索03124-起)。

## 可选触发方式（默认关闭）

| 触发 | 作用 | 开启位置 |
| --- | --- | --- |
| `Win` + `V` | 打开剪贴板窗口。会通过注册表禁用系统的 Win+V 剪贴板历史，修改后需**重启 Windows 资源管理器**才生效；关闭该选项会恢复系统设置 | 设置 → 触发 → 使用 Win+V 打开剪贴板 |
| 输入 `vv` 后按 `Tab`，或 2 秒内连按三次 `v` | 自动删掉刚输入的字母并显示剪贴板窗口 | 设置 → 触发 → 文本指令 vv+Tab / vvv |
| 按住鼠标侧键 X1 / X2 并滚动滚轮 | 打开便捷粘贴并切换条目；松开侧键粘贴，右键取消。只单击侧键（不滚动）时保留侧键原有行为 | 设置 → 便捷粘贴 → 鼠标侧键 + 滚轮 |

## 剪贴板窗口内（窗口已激活时）

| 按键 | 作用 |
| --- | --- |
| `Ctrl` + `F` | 聚焦搜索框（可用输入法） |
| `↑` / `↓` | 上一条 / 下一条 |
| `←` / `→` | 切换上方分类标签（循环） |
| `Home` / `End` | 第一条 / 最后一条 |
| `Shift` + `↑` / `↓` / `Home` / `End` | 从锚点连续多选（搜索框聚焦时不生效） |
| `Space` | 从当前选中块向下扩展一行多选（焦点在列表时） |
| `Ctrl` + `A` | 全选历史列表当前已加载的搜索／筛选结果；焦点在搜索框或编辑器时只全选文本 |
| `Tab` | 在剪贴板页和收藏页之间切换 |
| `Enter` | 粘贴当前选中项（多选时按选择顺序粘贴） |
| `Ctrl` + `C` | 复制选中项 |
| `Delete` | 删除选中项 |
| `Ctrl` + `P` | 置顶 / 取消置顶 |
| `Esc` | 关闭窗口（输入法组字时不关闭） |
| `1`–`9`、`0` | 粘贴第 1–10 条（需开启"使用数字键进行粘贴"，默认开启；搜索框里已有内容时数字进入搜索） |

历史列表全选包含滚动区域外已经加载的条目，按列表显示顺序选择；不额外读取数据库中尚未加载的匹配项。滚动加载下一批不会自动选中新条目，再按 `Ctrl+A` 才会包含它们。切换搜索或筛选后按新结果选择。收藏树的全选范围尚未定义，本次未新增收藏全选。

## 无焦点模式下

**设置 → 剪贴板 → 无焦点模式**（默认开启）时，剪贴板窗口弹出后**不抢前台焦点**，按键由程序转发，原来的输入框继续保持焦点。此时：

| 按键 | 作用 |
| --- | --- |
| `↑` / `↓` / `←` / `→` / `Home` / `End` | 同上（移动、切换分类、首末条） |
| `Enter` | 粘贴 |
| `Ctrl` + `A` | 全选历史列表当前已加载的搜索／筛选结果 |
| `Ctrl` + `C` | 复制历史列表选中项 |
| `Ctrl` + `P` | 置顶 / 取消置顶历史列表选中项 |
| 字母 | 写入顶部搜索 |
| `Backspace` | 删除一个搜索字符 |
| 数字 | 数字键粘贴（或进入搜索，规则同上） |
| `Tab` / `Shift` + `Tab` | 切换剪贴板 / 收藏页 |
| `Ctrl` + `F` | 进入正常焦点模式并聚焦搜索框，可用输入法 |
| `Esc` | 关闭窗口；弹层打开时先由对应弹层处理 |

上表适用于显式唤起窗口或点击窗口内部后建立的**完整列表接管**。主列表的 `Ctrl+A` / `Ctrl+C` / `Ctrl+P` 只接管不带 Shift、Alt、Win 的组合；一次按住只执行一次，主键的重复和释放不会同时作用于外部前台应用。搜索框、编辑器、菜单和对话框获得输入归属时继续遵循各自语义。

点击外部应用后，若窗口会话仍有效，则只保留普通数字键与普通 Esc；方向键、Home/End、Tab 及 Ctrl 组合交给外部应用。开始文字输入或编辑（包括 Ctrl+F）会结束数字接管；外部 Ctrl+A/C 作为选择／复制继续透传，不改变既有数字接管规则。退出后仅移回鼠标、悬停、Fold 展开或固定窗口都不会恢复，必须再次点击窗口内部或显式唤起。关闭无焦点模式后，打开窗口会激活并聚焦搜索框。

### CapsLock 引导键

在**无焦点模式**、窗口可见时，**按住 CapsLock** 再按字母：

| 按键 | 作用 |
| --- | --- |
| `CapsLock` + `I` | 上移一行 |
| `CapsLock` + `K` | 下移一行 |
| `CapsLock` + `J` | 切换到左边的分类 |
| `CapsLock` + `L` | 切换到右边的分类 |
| `CapsLock` + `O` | 删除一个搜索字符（等同 `Backspace`） |
| `CapsLock` + `Q` | 关闭窗口（等同 `Esc`） |

- 程序**不拦截 CapsLock 本身**，不会改变大小写锁定状态的处理，和 Quicker 的 CapsLock 扩展热键习惯一致。
- 松开 CapsLock 后再按 `I/J/K/L` 会输入到搜索。
- 用 `Ctrl` + `F` 进入正常焦点后，引导键暂不可用；关闭窗口再打开即可恢复。

## 当前版本没有的按键

以下按键出现在旧版说明或应用内帮助里，但 **GPUI 版本（0.31.x）代码中没有对应绑定**，不要告诉用户可以用：

- 多选时 `A` / `B` / `C`（顺序粘贴 / 逆序粘贴 / 取消选择）——请改用右键菜单里的"按选择顺序粘贴""逆序粘贴"。
- `M` 打开右键菜单——请直接右键条目。
- 列表里的 `Ctrl` + `Space` 切换单行选中。

尚未提供的绑定请通过 [反馈仓库](https://github.com/QuickerHub/cea-action-issues/issues) 提交建议；未列出的按键不表示已经提供。

## 便捷粘贴列表内

以下按键以默认 `Alt` + `` ` `` 为例：先打开便捷粘贴列表，并保持 `Alt` 按下。列表未打开时不接管 `Alt` + 字母键。

| 按键 | 作用 |
| --- | --- |
| `` ` `` / `↓` | 下一条，到末尾回到第一条 |
| `Q` / `↑` | 上一条，到开头回到最后一条 |
| 鼠标滚轮上 / 下 | 上一条 / 下一条，到头循环 |
| `1` / `2` | 主操作 / 次操作，具体操作随条目类型及设置变化 |
| `E` | 粘贴并发送回车（需启用此选项） |
| `D` | 删除当前条目 |
| `F` | 以当前项为终点准备连续粘贴队列（先进先出） |
| `Esc` | 取消本次便捷粘贴；连续粘贴时同时取消队列 |

松开 `Alt` 会粘贴选中项，或执行通过 `1` / `2` / `E` 选择的操作。按 `F` 只准备队列时，松开 `Alt` 不立即粘贴；之后每次便捷粘贴只贴队列头一条。
