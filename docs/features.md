# 功能清单

按 **设置** 侧栏分类列出当前版本（0.32.0）的功能，选项名称与软件内设置一致。各选项的默认值和取值范围见 [设置说明](settings.md)。

## 剪贴板

- 剪贴历史：自动记录，可暂停；**记录历史条目上限**；**允许重复复制**；**忽略空白剪贴板内容**；**黑名单**
- 分类标签：可自定义；出厂分类包含"网址""富文本"
- 列表：**单独分栏显示置顶项**、**图片与视频悬停预览**、**列表图片预览最大高度**、**列表布局密度**、**隐藏窗口后清空筛选**、**闲置后自动回到顶部** / **闲置时间（秒）**
- 窗口：**窗口失焦行为**（普通隐藏 / 贴边隐藏 / 自动折叠为标题栏）、**无焦点模式**
- 提示：**剪贴板改变时提示**、**提示位置**
- 粘贴：**列表项粘贴触发方式**、**使用数字键进行粘贴**、**富文本默认处理方式**、**默认规范粘贴**、**粘贴前延迟**、**粘贴文本时自动换行**、**使用 Shift+Insert 粘贴的进程**
- 清空与拆分：**清空时不提示**、**按行拆分最大行数**
- 与 Quicker：**收集Quicker步骤**、**剪贴板改变时触发自定义动作**、**预处理表达式**
- 编辑窗口：右侧吸附，"内容 / 属性"两页
- 右键菜单：按选择顺序粘贴、逆序粘贴、纯文本粘贴、连续粘贴、定位文件、收藏、置顶、删除、发送到局域网设备
- 底栏暂停 / 继续记录（开关，无定时）
- 临时图片保全（0.31.24）：截图软件等产生的已知临时图片另存，避免原文件被回收后记录失效
- 文件历史维护（0.31.24）：失效文件记录在宽限期后才清理，不删收藏与外部文件

## 便捷粘贴

- 快捷键按住预览、松开粘贴（默认 `Alt` + `` ` ``）
- **鼠标侧键 + 滚轮**（X1 / X2）
- **非置顶条数**、**记忆选中项**、**记忆有效期（秒）**
- 连续粘贴：**爆发间隔（秒）**、**队列上限**、**空闲超时（秒）**

## 触发

- **显示/隐藏剪贴板窗口**、**收藏面板**、**打开超级菜单** 三个全局快捷键
- **打开剪贴板窗口时的位置**
- **使用 Win+V 打开剪贴板**
- **文本指令 vv+Tab / vvv**

## 全局

- 外观：**界面主题**、**背景色**、**前景色**、**窗口背景图**、**背景混合比例**、**背景毛玻璃**、**界面语言**
- 系统：**开机自启**（默认开）、**以管理员身份运行**

## 数据管理

- **数据文件夹**（默认 `%LOCALAPPDATA%\BetterClipTauri`，修改需重启且不自动迁移）

## 面板（收藏 / 超级面板）

- **打开超级面板时的位置**、**面板样式**、**文件夹单击默认行为**、**文件单击默认行为**
- 收藏拖拽整理、保存到指定目录、路径搜索、撤销

## 资源管理器

- **记录资源管理器历史**、**历史记录上限**、**重开菜单显示数量**
- "打开 / 另存为"对话框目录跳转并保留文件名

## 超级菜单（含文件菜单、文本操作）

- 六分类：窗口、文件、收藏、书签、文本、剪贴板
- 窗口列表：单击切换、悬停操作、右键信息；状态标签、结束进程确认及默认关闭的缩略图
- 剪贴板双栏列表、内容预览、分页与就地删除
- 分类栏齿轮直接调整菜单设置
- **子菜单加载条目**、**显示菜单位置**、**快速加载子菜单**
- 文件菜单：**自定义目录**、**排序方式**、**显示方式**
- 文本操作搜索、用途／常用筛选、本地样例预览与分组规则管理

## 聚合搜索（0.31.24）

- 同时搜索收藏、剪贴板历史和已安装的 Quicker 动作，支持关键词与拼音
- 通过命令 `search` / `ceabox` 打开，可限定来源（clip / favor / action）

## 局域网与设备同步

- 设备发现与 6 位配对码配对、局域网互传（消息与文件，离线设备排队）
- Windows 设备间文本 / 静态图片自动同步：**设置 → 跨设备** 中一个总开关，初始开启；文本、图片分别可选，已配对设备直接使用
- 同图重新编码的精确判重，减少重复条目和同步回传
- **收到文件后加入剪贴板列表**（默认关闭）

## 托盘

- 左键显示剪贴板；右键菜单：打开主窗口、剪贴板、收藏、超级菜单、局域网互传、设置、帮助、退出

## 主界面与更新

- 统一首页、设置、跨设备、文本操作和帮助
- 图片持久缩略图缓存与失败重试，便捷粘贴纯图片预览
- 关于与更新：启动及每两小时检查，手动确认后下载、校验、原目录升级

## 诊断

- 启动失败或 panic 时显示原生错误框（可 `Ctrl` + `C` 复制）
- 便携包附带 `Start-ClipHostDiagnostics.cmd`，生成可发送的反馈 ZIP

## 尚未开放的功能

- **手机同步**：当前正式版**没有手机同步入口**，也没有公开发布的手机客户端，不对用户开放。
- **云同步 / 跨局域网同步**：未开放。
- **新的存储格式**：仍在隔离验证，正式版不会自动切换。
