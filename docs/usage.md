# 使用说明

本页按当前 GPUI 原生界面（0.31.12 起，按 0.31.26 核对）编写。具体选项名称以软件内 **设置** 为准；快捷键汇总见 [快捷键](hotkeys.md)，各选项默认值见 [设置说明](settings.md)。

## 打开剪贴板

- 全局快捷键：默认 `Ctrl` + `` ` `` 显示 / 隐藏剪贴板窗口，`Ctrl` + `Shift` + `` ` `` 打开收藏。
- 可选：`Win` + `V`、文本指令 `vv` + `Tab` / `vvv`（需在 **设置 → 触发** 开启）。
- 通过 Quicker 动作「剪贴板 n10」启动或唤起。
- 托盘图标左键单击（或双击）。

窗口出现的位置在 **设置 → 触发 → 打开剪贴板窗口时的位置** 设置（默认"鼠标右下"）。

## 系统托盘

程序常驻系统托盘，悬停提示文字为 "ClipHost GPUI · 剪贴板"。

- **左键单击 / 双击**：显示剪贴板窗口。
- **右键**：弹出菜单——打开主窗口、剪贴板、收藏、超级菜单、局域网互传、设置、帮助、退出。

"主窗口"包含首页、数据管理、帮助、局域网几个页面，以及设置入口。应用内 **帮助** 页有更详细的使用说明和命令列表。

## 主窗口（剪贴板窗口）

- 标题栏是搜索框；剪贴板与收藏用图标切换（也可按 `Tab` 切换），**暂停**（暂停记录）和 **设置** 在底栏。
- 列表上方是分类标签（如文字、图片、网址、富文本等），可在 **设置 → 剪贴板 → 分类标签** 自定义；**黑名单** 用于排除不想记录的来源程序。
- 右下角的紧凑弹层可以快速调整列表外观和交互预设。
- 历史列表有"返回顶部"按钮；也可开启 **闲置后自动回到顶部**（默认关闭）。
- 悬停的文字提示中，网址可以直接点击打开。
- 底栏显示条目总数；多选时显示"已选 N 条"。

### 暂停记录

底栏的 **暂停** 按钮是一个开关：点一下暂停记录新的剪贴板内容，底栏显示"已暂停记录"；再点一下（"继续记录"）恢复。**没有按时长暂停的选项**，暂停后需要手动恢复。

## 粘贴

- **列表项粘贴触发方式**（设置 → 剪贴板）：单击粘贴（默认）、单击复制后双击粘贴，或仅双击粘贴。
- **使用数字键进行粘贴**（默认开启）：按 `1`–`9`、`0` 粘贴列表对应位置的条目；搜索框里已有文字时数字会输入到搜索。
- **富文本默认处理方式**：复制、粘贴、拖放时可只保留文字（去掉格式及内嵌图片；独立图片、文件、动作步骤不受影响）。
- 其它粘贴选项：默认规范粘贴、粘贴前延迟、粘贴文本时自动换行、对指定进程改用 `Shift` + `Insert` 粘贴。

### 右键菜单

历史条目右键菜单包括：粘贴（多选时为"按选择顺序粘贴"）、复制、收藏、置顶 / 取消置顶、删除、纯文本粘贴（文本类）、逆序粘贴（多选时）、连续粘贴…、定位文件 / 定位文件夹（文件与图片）、编辑内容（单选时）、发送到局域网设备等。

### 便捷粘贴

按住 `Alt` + `` ` ``（默认）弹出最近剪贴板预览，滚轮或方向键切换条目，松开即粘贴。也可在 **设置 → 便捷粘贴** 改为"按住鼠标侧键 X1 / X2 + 滚轮"触发，右键取消。

### 连续粘贴

在右键菜单选"连续粘贴…"，或使用便捷粘贴的连续粘贴规则，把一段时间内连续复制的多条内容按顺序依次粘贴。队列规则（爆发间隔、队列上限、空闲超时）在 **设置 → 便捷粘贴**。

## 编辑条目

编辑窗口吸附在剪贴板右侧并保持等高，随主窗口移动、缩放和显隐；在列表中选择其它条目时同步切换。编辑器分"内容 / 属性"两页：内容页按类型提供编辑能力，属性页显示来源、路径及技术信息。

## 收藏

- 历史条目右键菜单可直接收藏：保存到总目录，或悬停选择指定目录、按路径搜索目录；保存后气泡显示位置，可撤销。
- 收藏、面板、自定义目录和分类支持拖拽整理（移动、复制、排序、撤销）；拖放提示会区分"插入到同级"和"放进文件夹"。
- 删除收藏夹时会清理相关引用；已失效的行可以在悬停时移除。

## 聚合搜索（0.31.24 起）

聚合搜索窗口可以同时查找 **收藏、剪贴板历史以及已安装的 Quicker 动作**，支持关键词与拼音。结果分批显示，较慢的动作查询不会挡住本地结果；会记住查询内容和本次会话里调整过的窗口位置。

打开方式：通过命令 `search`（或 `ceabox`）打开，可用 `search clip`、`search favor`、`search show --source action` 限定来源。命令可在 Quicker 中通过 Cea 的命令子程序调用。

> 待确认：聚合搜索是否有默认快捷键或专用 Quicker 动作入口（当前代码中没有为它设置默认全局快捷键）。

## 文件与图片记录的保留

- 截图软件等产生的已知临时图片，会在收录时另存一份，避免原文件被清理后历史记录不能用（0.31.24 起）。普通文件和多文件记录仍只保存原文件的路径。
- 文件类历史只在显示时检查原文件是否还在。普通未置顶记录的文件全部失效、且已超过 24 小时，再次确认后才清理该记录；收藏和外部文件本身不会被删除。

## 窗口失焦行为

**设置 → 剪贴板 → 窗口失焦行为**：失去焦点时 **普通隐藏**、**贴边隐藏**（默认）或 **自动折叠为标题栏**。

## 超级菜单与文件菜单

- 默认 `Win` + `` ` `` 打开超级菜单，包含 **窗口、文件、收藏、书签、文本、剪贴板** 六个分类，切换栏位于当前屏幕顶部居中。也可从托盘右键菜单或 Quicker 动作「超级菜单 n10」打开。
- 超级菜单、文件菜单和文本操作的设置合并在 **设置 → 超级菜单** 一个分类里，分区标签与长页滚动联动。
- 0.31.28 起，窗口分类使用普通列表；悬停或点击窗口行查看和复制窗口信息，右键打开管理菜单。查看信息保持外部窗口的输入焦点，激活窗口通过明确的管理命令执行。
- 文件菜单维护自己的 **自定义目录** 列表，可设置排序方式与显示方式。
- **设置 → 资源管理器** 可开启"记录资源管理器历史"，并设置历史记录上限、重开菜单显示数量。

## 打开 / 另存为窗口的目录跳转

在标准"打开 / 另存为"对话框（含 Chrome 等浏览器的另存为窗口）中跳转到目标文件夹时，会保留已填写的文件名；繁忙或失败时停止重复跳转。部分原生增强目前只有 x64 实现。

## 局域网配对

局域网功能在 **主窗口 → 局域网**（或托盘右键 → 局域网互传）。两台电脑需要在同一局域网。

1. 两台电脑都打开局域网页，**开启互传**（关闭时其他设备无法发现本机）。可在"本机设备名称"里改一个好认的名字。
2. 在其中一台点 **添加设备 / 查找设备**，从附近设备列表里选择对方。
3. 对方屏幕上会显示 **6 位配对码**；在本机输入该码确认，即完成配对。配对码可以刷新（旧码立即失效）。
4. 已配对设备会出现在列表里，可随时 **解除配对**（历史消息保留，之后发送需重新配对）。

找不到设备时：确认两台设备在同一局域网、对方已开启互传，并允许 ClipHost 通过 Windows 防火墙。

## 局域网互传

- 互传面板贴附在剪贴板右侧，与编辑共用右栏；底栏入口显示打开状态。
- 打开互传时，可点击历史条目或拖入内容发送；输入草稿会保留。对方离线时，内容会排队等待上线后自动发送。
- 历史条目右键菜单也可直接发送到局域网设备。
- **收到文件后加入剪贴板列表**（默认关闭）：完整接收的多个文件合成一条本机文件记录；加入失败可单独重试，无需重传。

## Windows 设备间剪贴板同步

在 **设置 → 设备同步** 中控制文本、静态图片自动同步；局域网 **设备与连接** 中也能找到同一个总开关。以下说明适用于 0.31.26 起的版本：

- 同步初始开启，文本和图片初始均选中，可分别取消，至少保留一种。升级时已经明确关闭的总开关会保留。
- 同一局域网内完成设备配对后即可双向同步；收到内容后保存到历史并写入当前剪贴板，无需再配置发送、接收方向或接收动作。
- 连续相同内容不会重复发送；收到与当前相同的内容不重复写入；延迟或重试送达的内容不会覆盖当前剪贴板。
- 同一张图片仅编码或标准附加信息不同、像素完全一致时复用一个条目；图片内容确实变化时保留新条目。
- 文件仍使用手动互传。暂停自动同步使用总开关，不影响手动互传或已有配对。

已验证两台 Windows 的文本和图片收发，以及模拟第三方重新编码后的去重。多款同步工具同时运行仍可能互相影响，可只保留一套自动同步。真实微信客户端、三台以上设备及锁屏 / 睡眠恢复未由上述检查替代。

验证范围和已知边界见 [已知问题](known-issues.md#局域网与设备同步)。

**手机同步目前不对用户开放**：当前正式版没有手机同步入口，也没有公开发布的手机客户端。

## 外观与语言

**设置 → 全局**：界面主题、背景色 / 前景色、窗口背景图、背景混合比例、背景毛玻璃、界面语言。

## 与 Quicker 配合

- **设置 → 剪贴板** 中与 Quicker 相关的选项：**收集Quicker步骤**、**剪贴板改变时触发自定义动作**、**预处理表达式**。
- 剪贴板、收藏、超级菜单等功能不依赖 Quicker；聚合搜索里的"Quicker 动作"来源需要 Quicker。
