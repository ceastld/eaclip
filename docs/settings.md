# 设置说明

按软件设置页整理：选项名称与软件内一致，"默认"一列是程序出厂默认值（已有旧配置的用户以自己的配置为准）。打开方式：剪贴板窗口底栏 **设置**，或托盘右键 → 设置。设置页顶部可以搜索选项名称。

统一主界面包含首页、全局、触发、便捷粘贴、剪贴板、跨设备、面板、资源管理器、超级菜单、数据管理、帮助及关于与更新。文本操作归超级菜单子项；设备发现、配对与剪贴板同步集中在 **跨设备**，消息仍显示在剪贴板右侧互传栏。

## 跨设备

在设置侧栏选择 **跨设备**，进行局域网设备配对并控制自动剪贴板同步。服务开启时进入页面自动取得有效配对码，按实际期限续码；页面隐藏或最小化时暂停生成。

| 选项 | 默认 | 说明 |
| --- | --- | --- |
| 剪贴板同步 | 开 | 已配对的局域网电脑双向同步；关闭后暂停自动同步，保留配对和内容选择 |
| 文本 | 开 | 自动同步普通文本 |
| 图片 | 开 | 自动同步静态 PNG / JPEG 图片；文本、图片至少保留一种 |

升级时此前明确关闭的总开关会保留。开启同步后，收到的内容保存到历史并写入当前剪贴板，无需逐设备配置方向或接收动作；文件继续手动互传。用法见 [使用说明 · 设备同步](usage.md#windows-设备间剪贴板同步)。

## 局域网（设置 → 跨设备）

开启 / 关闭互传、本机设备名称、配对码、已配对设备、剪贴板同步状态，以及收到文件后加入剪贴板列表。自动同步的总开关和文本 / 图片选项与 **设置 → 跨设备** 共用。用法见 [使用说明 · 局域网配对](usage.md#局域网配对)。

## 关于与更新

展示当前版本、程序目录与数据目录，提供手动检查。正常启动就绪后及每两小时自动检查一次；自动检查只读取版本信息，不下载或安装。发现新版本后点击 **更新并重启**，下载校验后在原程序目录升级，历史、收藏与配置继续保留。开发版只允许检查更新。
