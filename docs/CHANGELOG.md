# 更新记录

只列出在 [ceastld/eaclip](https://github.com/ceastld/eaclip/releases) 公开发布的版本。每版完整说明见对应 Release 页面。

0.31.18、0.31.19、0.31.20、0.31.22、0.31.25、0.31.27 是未公开发布的候选版本，其内容分别由 0.31.21、0.31.23、0.31.26 和 0.31.28 承接，因此不单独列出。

## 0.32.6（2026-10-31）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.32.6) · Windows x64

- 修复唤出剪贴板后可能马上消失的窗口焦点与隐藏竞态。
- 优化历史图片缩略图尺寸与缓存；自动回顶默认开启，隐藏超过 0.5 秒后回顶并清除选中，快速重开保留位置。
- 修复便捷粘贴的选择记忆，并在设置搜索中标明选项所属页面。
- 贴顶晾衣绳支持展开延迟，超级菜单书签可在菜单内切换来源；改进自动更新检查。

## 0.32.5（2026-10-29）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.32.5) · Windows x64

- 修复贴顶晾衣绳首次展开时触发内部错误、导致程序退出的问题。
- 修复固定纸片、收起晾衣绳后的窗口与点击区域更新，避免收起区域继续拦截鼠标。
- 通过 16 项相关单元测试与 9 阶段 Windows 原生窗口回归；第三方应用拖放、多屏及混合缩放的完整体验未在本次回归中重新验收。

## 0.32.3（2026-10-29）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.32.3) · Windows x64

- 修复隐藏剪贴板、菜单和提示窗后残留置顶状态的问题，同时保留可见主窗的置顶，并恢复伴随窗折叠、展开后的正确层级。
- 超级菜单分类栏调整到菜单上方，切换分类和打开浏览栏时保持位置；设置按钮并入分类栏，右键分类可直达对应设置。
- 新增默认关闭的「贴顶晾衣绳」，可在「设置 → 超级菜单 → 文件菜单」开启；支持悬停浏览、固定纸片、标签排序、拖入文件夹、拖出文件，以及取下、撤销和键盘操作。
- 缩短平滑滚动的拖尾，减少缩略图重复解码，改善列表滚动响应。

## 0.32.2（2026-10-28）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.32.2) · Windows x64

- 减少后台轮询和空闲重绘，降低持续运行开销。
- 文件菜单支持固定浏览与双目录，改进资源管理器重开历史的搜索、移除、撤销和排除目录。
- 改进整行拖动预览、多选及复制／移动提示。
- 修复图片首次加载和滚动时的闪烁，以及数据库未完成事务的启动恢复。

## 0.32.1（2026-10-25）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.32.1) · Windows x64

- 修复超级菜单意外展开贴边隐藏的剪贴板；改进悬浮预览的切换、位置、文件卡片和文本／代码内容。
- 重做进程筛选与自定义分类弹层，保持操作按钮可见。
- 便捷粘贴改为 Q 上一条、反引号下一条、F 准备连续粘贴。

## 0.32.0（2026-10-24）

- 升级超级菜单剪贴板双栏、窗口操作与就地设置，以及文本操作和历史列表快捷键。

## 0.31.31（2026-10-22）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.31) · Windows x64

- 修复便捷粘贴加载期间快速操作丢失或错序、连续粘贴准备后的行操作，以及 E 和系统组合键的接管。
- 修复松键后立即按 Esc 仍粘贴、单键快捷键和输入中断后的会话残留。

## 0.31.29（2026-10-22）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.29) · Windows x64

- 兼容异常旧记录并改进数据库启动恢复，保留异常内容的只读保护。

## 0.31.28（2026-10-21）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.28) · Windows x64

- 修复历史外观字段的新旧名称共存时启动失败；读取兼容旧名，保存时统一为单一字段，保留未知配置。
- 窗口分类恢复普通列表与级联信息菜单，悬停查看和复制，右键进行窗口管理，移除窗口图片轮播。
- 查看信息保持外部窗口的输入焦点，激活窗口通过明确菜单命令执行。
- 常规发布仅提供 x64；Quicker V1 / V2 入口更新至 `0.31.27.1`，统一选择 x64 宿主，暂停 ARM64 自动判断和下载。
- 继续使用原历史、收藏与配置。

## 0.31.26（2026-10-21）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.26) · Windows x64 / ARM64

- 设备同步直接放入设置界面，一个总开关控制；初始开启，文本和图片分别可选，配对后直接使用。
- 移除逐设备方向和接收动作的重复配置，旧的明确暂停状态保留。
- 同图重新编码或增加标准 PNG 附加信息时，精确判重并抑制同步回声；不同像素仍作为新内容。

## 0.31.24（2026-10-21）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.24) · Windows x64 / ARM64

- 新增聚合搜索窗口，可同时查找收藏、剪贴板历史及已安装的 Quicker 动作，支持关键词与拼音；结果分批显示，较慢的动作查询不阻塞本地结果。
- 改进搜索窗口的唤起聚焦、搜索栏拖动、默认居中和中英文显示；保留查询及同一会话内调整过的窗口位置。
- 保全截图软件等产生的已知临时图片，避免原文件回收后历史记录无法使用；普通文件和多文件记录继续保留原引用。
- 文件历史仅在展示时检查；普通未置顶记录全部失效并超过 24 小时后，再次确认才清理，保留收藏与外部文件。
- 修复部分 Windows 位图的读取兼容性，改进局域网图片同步的像素一致性；文本、图片和第三方重复写入继续按内容去重。
- 调整超级菜单展开按钮与行高，改善文件级联菜单的紧凑布局。
- 剪贴板 n10 与超级菜单 n10 使用宿主 `0.31.24.0`；Quicker V1 / V2 入口更新为 `0.31.24.1`，基本宿主兼容下限不变。

## 0.31.23（2026-10-20）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.23) · Windows x64 / ARM64

- 修复部分电脑开机早期自动启动时，可能提示 `overflow when subtracting duration from instant` 并退出的问题。
- 修正采集状态及全局采集抑制状态的初始化，默认仍立即允许采集。
- 改进设置窗口打开失败时的诊断信息。
- 剪贴板 n10 与超级菜单 n10 要求宿主 `0.31.23.0`；入口 DLL 继续复用 `0.31.14.1`。

## 0.31.21（2026-10-20）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.21) · Windows x64 / ARM64

- 新增 Windows 设备间可选剪贴板同步（文本、静态图片），总开关及每台设备的发送、接收初始关闭。
- 每台设备可分别选择是否保存到历史、是否替换当前剪贴板；文件继续手动互传。
- 新增「收到文件后加入剪贴板列表」（初始关闭）。
- 局域网互传贴附剪贴板右侧，与编辑共用右栏；精简消息、文件卡片与输入框。
- 超级菜单六分类切换栏移到当前屏幕顶部居中；修复「全局菜单设置」误打开剪贴板；超级菜单相关设置合并为一个侧栏分类。
- 优化数字键粘贴与外部输入衔接，补充状态及暂停原因；历史搜索框更紧凑。
- 修复部分显示缩放下短消息只显示首字，以及右栏打开时靠屏边拖动主窗口回跳。

## 0.31.17（2026-10-19）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.17) · Windows x64 / ARM64

- 修正显卡设备重建时的资源释放顺序，降低显示器恢复、显卡驱动重置时的崩溃风险。
- 增加主窗口关闭、主动退出及正常结束的诊断记录（不含剪贴板正文）。

- 历史列表删除后局部更新，减少连续删除时的跳动；调整暗色图标、文本编辑等细节。

## 0.31.16（2026-10-18）

[Release](https://github.com/ceastld/eaclip/releases/tag/rust-v0.31.16) · Windows x64 / ARM64

- 历史条目使用更紧凑的右键菜单，整合常用操作、收藏和局域网发送。
- 收藏支持保存到总目录、悬停选择指定目录和路径搜索，保存后显示位置并可撤销。
- 列表常用设置改为右下角紧凑弹层；恢复返回顶部按钮，新增默认关闭的闲置回顶选项。
- 图片列表按可见内容加载并共享缓存预算；显示缩图不改写原图。
- 补充启动失败提示和可导出的诊断信息。
