# Rust ClipHost 0.31.14

发布日期：2026-10-16。本版重点改进原生编辑、网址查找与收藏整理，并修复便捷粘贴、窗口菜单和显示器恢复时的稳定性问题。提供 Windows x64 和 ARM64 便携包，使用 GPUI 原生界面，无需 WebView2。

## 稳定性修复

- 修复按住 Alt 连续使用便捷粘贴时，浮窗无法及时出现或提前关闭的问题。
- 修复超级菜单窗口分类及相关窗口操作菜单在空闲后卡住的问题。
- 修正显示器断连或恢复时，隐藏的剪贴板窗口和透明浮层被错误显示的处理。息屏后主屏点击异常的现场复验仍在继续。

## 编辑与主窗口

- 编辑窗口吸附在剪贴板右侧并保持等高，随主窗移动、缩放和显隐；列表选择其他条目时同步切换编辑内容。
- 编辑器重新整理为“内容／属性”两页，按内容类型展示已有编辑能力，完整呈现来源、路径及技术信息；切页保留草稿与图片缩放。
- 搜索移入标题栏，剪贴板与收藏使用图标切换，暂停和设置移到底栏。点击搜索框外可退出搜索聚焦，切页保留各自查询。

## 网址查找与文字提示

- 新增“网址”分类，统一列表高亮、筛选和文字提示的识别规则；支持常见无协议域名及 Markdown 链接，减少邮箱、文件名和路径误识别。
- 已有自定义分类首次升级只补充一次“网址”，保留名称和顺序；移除后不反复补回。“富文本”加入新配置及恢复默认后的出厂分类。
- 悬浮文字提示中的网址可以直接点击打开，长文字提示滚动时显示位置条。

## 收藏与细节改进

- 拖放提示区分同级插入与放入文件夹，插入线按目标层级显示；展开文件夹下沿表示插到第一个子项之前。
- 改善拖放后的刷新和预览复用。删除收藏夹时清理相关引用，已有失效行可以在悬停时移除。
- 改进 Chrome 等“另存为”窗口的目录跳转和原文件名保留，避免超时后的重复导航。
- 减少复制提示首次出现、堆叠和消失时的闪烁与尺寸跳变，改善跨 DPI 的位置和尺寸保持。

## 验证范围

原生回归与隔离启动检查覆盖窗口状态、包架构、随包运行库及基础健康启动；完整中文输入法、物理拖放、第三方应用回贴及长期双屏息屏场景继续按实际验证结果记录。文件对话框的部分原生增强仍仅有 x64 实现，ARM64 完整 Quicker 桌面流程仍待实机验证。
