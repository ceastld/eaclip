# ClipHost 0.32.7：双列收藏与隐私遮挡

- 剪贴板右上角的「⋯」可直接开关收藏侧栏。左右两列共用搜索框，可把一条或多条历史拖入右侧当前收藏夹，并撤销整批收藏。
- 收藏页和侧栏的图片按可用空间等比显示。悬停条目可查看完整文字、放大图片，以及预览文件和图文内容。
- 新增「遮挡疑似密码和密钥」，默认关闭。开启后，剪贴板与收藏的只读内容会遮挡识别到的敏感文字，编辑时仍可查看原文。遮挡只作用于显示，保存和复制仍使用原文。
- 屏幕顶边入口改为超级菜单的分类按钮。在超级菜单的通用设置中开启「贴顶弹出」后，指针在顶边停留即可唤出。
- 修复长内容和行尾统计重叠，以及系统拒绝切换焦点时剪贴板窗口可能消失的问题。

本版提供 Windows x64。[下载便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.7/eaclip-0.32.7-windows-x64.zip)，完整解压后运行。升级继续使用原有历史、收藏与设置。
