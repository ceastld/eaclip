# ClipHost 0.32.2：降低后台占用与文件浏览改进

- 减少后台空闲时的轮询和界面重绘，降低剪贴板与超级菜单的空闲开销。
- 超级菜单文件分类新增停靠浏览栏，支持目录浏览和双栏查看。
- 增加重开历史管理，可搜索、移除记录、撤销删除，以及设置不再记录的目录。
- 条目拖出预览改为整条快照，改善多选条目及复制、移动状态提示。
- 改善列表图片首次加载和滚动时的闪烁。
- 修复异常退出后，数据库未完成事务可能导致无法启动的问题。

本版仅提供 Windows x64。下载 [x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.2/eaclip-0.32.2-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」安装或升级。「超级菜单 n10」使用同一宿主。继续使用原历史、收藏与设置。

本版完成自动化回归及发行包检查；物理输入法、第三方应用回贴和完整拖放体验继续沿用既有验收边界。
