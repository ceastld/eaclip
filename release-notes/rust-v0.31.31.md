# ClipHost 0.31.31：便捷粘贴键盘与退出修复

- 修复便捷粘贴候选加载期间，快速按下 1／2、E、Q、D 或方向键时操作可能丢失、错序的问题。
- 修复按 Q 准备连续粘贴后，再选择贴图等行操作或 E「粘贴并回车」时无反应的问题；仅准备队列时松键仍不自动粘贴。
- 修复关闭 E「粘贴并回车」后仍吞掉 E，以及便捷粘贴按键误触发后方主窗口搜索的问题；额外修饰键组合交还前台应用，避免干扰系统快捷键。
- 修复松开快捷键后立即按 Esc 仍发生粘贴的问题。连续粘贴浮层内按 Esc 同时取消本次队列，长按不会继续关闭底层窗口，旧取消也不会影响新队列。
- 修复单键快捷键、快速松键及输入中断时的会话残留，避免浮窗卡住或迟到显示。本版仅提供 Windows x64 包。

下载 [Windows x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.31.31/eaclip-0.31.31-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」安装或升级。原有历史、收藏、配置和图片目录继续保留。
