# ClipHost 0.32.3：窗口层级修复与文件晾衣绳

- 修复隐藏剪贴板、菜单和提示窗后残留置顶状态的问题，同时保留可见主窗的置顶，并恢复伴随窗折叠、展开后的正确层级。
- 超级菜单分类栏调整到菜单上方，切换分类和打开浏览栏时保持位置；设置按钮并入分类栏，右键分类可直达对应设置。
- 新增默认关闭的「贴顶晾衣绳」，可在「设置 → 超级菜单 → 文件菜单」开启；支持悬停浏览、固定纸片、标签排序、拖入文件夹、拖出文件，以及取下、撤销和键盘操作。
- 缩短平滑滚动的拖尾，减少缩略图重复解码，改善列表滚动响应。

本版仅提供 Windows x64。下载 [x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.3/eaclip-0.32.3-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」安装或升级。「超级菜单 n10」使用同一宿主。继续使用原历史、收藏与设置。

窗口层级修复已通过 Windows 11 原生自动化回归；Windows 10 22H2 的间歇性任务栏／Alt+Tab 切换问题尚未完成现场复测。物理输入法、第三方应用回贴和完整拖放体验继续沿用既有验收边界。
