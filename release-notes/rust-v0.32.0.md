# ClipHost 0.32.0：统一主界面与超级菜单升级

- 统一主界面：将首页、设置、帮助和设备管理集中到一个窗口；「跨设备」整合局域网配对与剪贴板同步，配对码按有效期自动更新。
- 重做超级菜单的剪贴板分类：双栏展示列表与内容预览，按类型显示图片、文件、链接和文本，支持滚动加载、就地删除、文件右键操作与子目录展开。
- 改进窗口菜单：单击切换窗口，悬停展开操作，右键查看与复制窗口信息；补充状态标签、PID 和结束进程确认，窗口缩略图默认关闭。
- 超级菜单内可直接调整当前分类及通用设置；分类栏按钮统一大小，支持在栏内滚轮循环切换。「超级菜单 n10」与快捷键共用上次分类记忆，首次或宿主重启后打开收藏。
- 重做文本操作的使用与管理界面，提供搜索、用途与常用筛选、键盘选择、本地样例预览，以及分组、编辑和按任务新建；继续保留已有规则。
- 完善历史列表的全选、复制、置顶及多选顺序粘贴，改进数字序号和暂停状态提示；恢复清空非置顶历史入口。
- 增加图片缩略图缓存与临时失败重试，减少重复解码；补齐 QQ／微信纯图片的便捷粘贴预览，避免无正文条目显示为空白。
- 新增「关于与更新」：启动后及运行期间每两小时检查新版本，保留手动检查；点击「更新并重启」后下载、校验并在原目录升级，替换失败时恢复原文件。自动检查不下载、不安装。
- 修复文件菜单对「此电脑」「回收站」等系统位置的识别，以及剪贴板分页删除时迟到结果重新插入条目的问题。

本版仅提供 Windows x64。下载 [x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.0/eaclip-0.32.0-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」安装或升级。「超级菜单 n10」使用同一宿主。原有历史、收藏、文本规则、配置及图片继续保留。

版本已进行自动回归、隔离运行与原包校验；物理输入法、第三方应用回贴及软件内更新的完整桌面流程不由这些检查替代。旧版首次升级到本版仍通过便携包或 Quicker 动作完成。
