# ClipHost 0.31.29：数据库启动兼容与数据保护

- 修复旧收藏条目残留子项信息时，提示“C# 非收藏夹条目包含 Children”并无法启动的问题；兼容读取并保留原始数据。
- 历史、收藏或使用统计出现单条格式异常时，保留异常记录并以只读保护启动，可以查看其余正常内容。
- 只读保护期间暂停业务写入与自动清理，保留收藏目录顺序、引用和未完成的操作记录，防止部分数据被当作完整结果覆盖保存。
- 提供异常记录的定位信息，便于进一步恢复；原数据修复后重启即可重新加载。
- 继续使用原有历史、收藏、配置和图片目录，本版仅提供 Windows x64 包。

下载 [Windows x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.31.29/eaclip-0.31.29-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」安装或升级。

数据库文件本身损坏、目录权限或磁盘空间等问题仍会明确报错，需要恢复数据或修正环境后重试。程序不会通过删除原库恢复启动。
