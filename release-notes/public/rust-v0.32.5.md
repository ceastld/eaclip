# ClipHost 0.32.5：修复贴顶晾衣绳展开崩溃

- 修复贴顶晾衣绳首次展开时触发内部错误、导致程序退出的问题。
- 修复固定纸片、收起晾衣绳后窗口与可点击区域未及时更新的问题，避免已收起的区域继续拦截鼠标。

本版发布包通过 GitHub Actions 构建，仅提供 Windows x64。下载 [x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.5/eaclip-0.32.5-windows-x64.zip)，完整解压后运行。继续使用原历史、收藏与设置；贴顶晾衣绳仍默认关闭，可在「设置 → 超级菜单 → 文件菜单」开启。

本次修复已通过 16 项相关单元测试与 9 阶段 Windows 原生窗口回归，覆盖首次展开、反复收起、固定纸片与点击区域更新。第三方应用拖放、多屏及混合缩放的完整体验未在本次回归中重新验收。
