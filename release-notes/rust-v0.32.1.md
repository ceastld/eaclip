# ClipHost 0.32.1：贴边隐藏修复与悬浮预览改进

- 修复打开或操作超级菜单时，贴边隐藏的剪贴板意外展开的问题；鼠标移到剪贴板露出条仍可正常恢复。
- 改进条目悬浮预览：首次等待期间预先解码，连续经过其它条目时直接切换；预览保持同一侧并平滑调整位置和尺寸，减少来回跳动。
- 图片、单个图片或视频文件支持整条悬停预览；图文混排按原顺序显示。多文件条目可在文件卡片中查看列表、打开或定位文件，并级联显示预览。
- 增加常见文本和代码文件的有限内容预览与语法高亮；超级菜单文件列表也支持图片、静音视频及文本预览。
- 重做进程筛选与自定义分类弹层：头尾固定、正文独立滚动，保存和取消按钮始终可见；支持搜索软件、直接编辑进程标签，以及恢复默认后的撤销。
- 调整便捷粘贴按键：保持 Alt 按下时，反引号选下一条，Q 选上一条，F 准备连续粘贴；方向键、滚轮和松键提交沿用原有规则。

本版仅提供 Windows x64。下载 [x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.1/eaclip-0.32.1-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」安装或升级。「超级菜单 n10」使用同一宿主。继续使用原历史、收藏与设置。

本版完成自动化回归及发行包检查；物理输入法、第三方应用回贴和完整拖放体验继续沿用既有验收边界。
