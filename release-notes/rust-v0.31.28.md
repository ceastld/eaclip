# ClipHost 0.31.28：修复配置启动失败与窗口信息菜单

- 修复历史外观配置的新旧字段名共存时，提示“WindowBackgroundColor 有重复新旧/大小写名称”并无法启动的问题。读取兼容历史名称，保存时统一为一个字段，不重置用户配置。
- 超级菜单的窗口分类恢复为紧凑列表与级联菜单，移除窗口图片轮播。
- 悬停或点击窗口行查看标题、句柄、类名、进程名、进程路径和位置，可复制单项或完整信息；查看信息保持外部窗口的输入焦点。
- 右键窗口打开管理菜单，保留置顶、最小化、最大化、居中、不透明度及已有管理命令；激活窗口通过明确的菜单命令执行。
- 本版仅提供 Windows x64 包。Quicker V1 / V2 入口更新为 0.31.27.1，统一下载和加载 x64 宿主，暂时关闭 ARM64 自动选择。
- 继续使用原有历史、收藏、配置和图片目录，不移动用户数据。

下载 [Windows x64 便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.31.28/eaclip-0.31.28-windows-x64.zip)，完整解压后运行；也可运行更新后的「剪贴板 n10」或「超级菜单 n10」安装或升级。

历史 ARM64 包仍保留，本次不继续更新；Windows on ARM 的兼容运行未纳入本版验收。
