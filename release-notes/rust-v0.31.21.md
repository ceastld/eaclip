# Rust ClipHost 0.31.21

发布日期：2026-10-20。本版新增 Windows 设备间的可选剪贴板同步，并优化局域网互传、超级菜单设置与数字键提示。

## Windows 设备剪贴板同步

- 在局域网「设备与连接」中，可为已配对电脑开启文本、静态图片自动同步。总开关及每台设备的发送、接收初始关闭；文本初始允许，图片需另行开启。
- 每台设备可独立选择是否保存收到的内容到历史、是否替换当前剪贴板，支持只收集历史或临时跨设备接力。文件继续使用手动互传。
- 连续相同内容不会自动重复发送，收到与当前相同的内容时避免重复写入；延迟或重试交付不覆盖当前剪贴板。第三方软件改写后的内容不保证能识别为同一内容。
- 新增「收到文件后加入剪贴板列表」，初始关闭。完整接收的多个文件组成一条本机文件记录；加入列表失败可单独重试，无需重新传文件。
- 修正设备同步及收到文件设置卡片在窄窗中的换行与开关布局。

## 局域网互传与窗口

- 互传贴附剪贴板右侧，与编辑共用右栏。打开互传时，可点击历史条目或拖入发送，输入草稿保持；底栏入口显示打开状态。
- 精简消息、文件卡片与滚动条，输入框默认一行，随输入自动增高。
- 修复部分显示缩放下短消息只显示首字，以及编辑／互传右栏打开时靠屏边拖动主窗口回跳的问题。

## 超级菜单与数字键提示

- 超级菜单六分类切换栏调整到当前屏幕顶部居中，修复「全局菜单设置」误打开剪贴板的问题。
- 超级菜单相关设置合并到一个侧栏分类，页内分区标签与连续长页滚动联动，统一收纳文件菜单与文本操作管理入口。
- 优化数字键粘贴与外部输入的衔接，补充状态及暂停原因。悬停说明始终可关闭，手动说明会自动收起，避免长期遮挡列表。
- 历史搜索框更紧凑，为标题栏拖动保留空间。

## 数据与兼容

继续使用原有历史、收藏、配置及图片目录，**不移动用户数据，也不自动迁移到实验存储格式**。自动同步需要用户单独开启，配对或打开互传窗口不会自动授权同步。

Quicker 入口 DLL 继续独立管理，复用 `0.31.14.1`；x64 最低兼容要求保持 `0.31.7.0`，ARM64 保持 `0.31.14.1`。剪贴板 n10 与超级菜单 n10 的宿主要求随本次发布同步。
