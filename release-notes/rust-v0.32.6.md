# ClipHost 0.32.6：窗口稳定性与列表体验优化

- 修复唤出剪贴板后可能马上消失的问题：避免旧焦点状态、迟到的前台刷新或焦点失败误隐藏新窗口。
- 优化历史图片缩略图的显示尺寸与缓存复用，降低列表加载图片时的开销。
- 自动回到顶部默认开启。隐藏超过 0.5 秒后回顶并清除选中；快速重开保留位置。使用窗口、编辑或打开弹层时暂缓，搜索与筛选保持。
- 修复便捷粘贴关闭选择记忆后再开启仍恢复旧选中的问题，并在设置搜索中标明选项所属页面。
- 贴顶晾衣绳支持设置展开延迟，默认 200 毫秒；超级菜单书签可在菜单内切换来源。
- 改进自动更新检查，正式发布后主动刷新版本信息。

仅提供 Windows x64。[下载便携包](https://github.com/ceastld/eaclip/releases/download/rust-v0.32.6/eaclip-0.32.6-windows-x64.zip)，完整解压后运行；继续使用原历史、收藏与设置。

窗口隐藏竞态已有确定性回归；QQ 与后台游戏的完整现场、多屏混合缩放、第三方输入法和拖放体验仍需结合实际使用核对。
