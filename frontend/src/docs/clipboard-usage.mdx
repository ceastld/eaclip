# 剪贴板使用说明

浏览剪贴历史、搜索筛选、选中并粘贴到其它应用。列表会随剪贴板变化自动刷新。

## 全局快捷键

在任意应用中可用（需 ClipHost 在运行）。可在 **设置 → 触发** 或 **设置 → 便捷粘贴** 中修改。

| 快捷键 | 作用 | 说明 |
| --- | --- | --- |
| Ctrl + 反引号键 | 显示 / 隐藏剪贴板窗口 | 默认键位，Esc 下方；留空则禁用 |
| Ctrl + Shift + 反引号键 | 显示 / 隐藏收藏页 | 默认键位；留空则禁用 |
| Alt + 反引号键 | 便捷粘贴 | 默认键位；按住弹出最近剪贴板预览，滚轮或方向键切换，松开粘贴；在 **设置 → 便捷粘贴** 修改，留空则禁用 |
| Win + 反引号键 | 打开超级菜单 | 默认键位；窗口、文件、收藏、书签、文本、剪贴板六个分类，不依赖 Quicker；留空则禁用 |
| `Win+V` | 打开剪贴板 | 需在设置中开启「使用 Win+V 打开剪贴板」；会接管系统剪贴板历史，生效后需重启资源管理器 |
| `vv` → `Tab` | 打开剪贴板 | 任意输入框输入 `vv` 后按 Tab，自动删除 `vv` 并唤起窗口；需开启「文本指令 vv+Tab / vvv」 |
| `vvv` | 打开剪贴板 | 在 2 秒内连按三次 `v`，自动删除 `vvv` 并唤起窗口；与上项共用同一开关 |

## 窗口内快捷键

焦点在剪贴板页、且未打开对话框 / 未在输入框内编辑时生效。打开筛选、清空确认、添加文本等面板时，下列快捷键会优先交给面板，避免误粘贴。

### 粘贴

| 快捷键 | 作用 | 说明 |
| --- | --- | --- |
| `Enter` | 粘贴 | 有选中项时按选择顺序粘贴；无选中时粘贴当前高亮行 |
| `1`–`9` | 粘贴第 1–9 条 | 对应当前可见列表从上到下编号；需在设置中开启「使用数字键进行粘贴」 |
| `0` | 粘贴第 10 条 | 同上；主键盘与小键盘数字均可 |

窗口未聚焦但仍在屏幕上时（**无焦点模式**），ClipHost 通过低层键盘钩子转发按键，**不会激活剪贴板窗口或抢占前台焦点**；仅 `Ctrl+F` 会进入正常焦点模式以便使用输入法。

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓` | 移动高亮行 |
| `←` / `→` | 切换顶部分类标签 |
| `Home` / `End` | 跳到首条 / 末条 |
| `Enter` | 粘贴（同有焦点时） |
| 字母 / 数字 | 写入顶部搜索（虚拟搜索） |
| `Backspace` | 删除搜索字符 |
| `Ctrl` + `F` | 进入正常焦点模式并聚焦搜索框，可使用输入法 |
| `Esc` | GPUI：关闭窗口，弹层先由对应弹层处理；WebView：先清空多选 / 搜索，再关闭 |

数字键：若已开启「使用数字键进行粘贴」且搜索框为空，则粘贴对应条目；否则字符进入搜索框。

### 扩展热键（CapsLock 引导）

与 Quicker **扩展热键**同一套习惯：把 **CapsLock 当作引导键**，再按字母即可操作列表，**无需把焦点切到剪贴板窗口**。宿主**不会拦截 CapsLock 本身**，避免与 Quicker 或其它软件的 CapsLock 引导状态不同步。

| 快捷键 | 作用 | 说明 |
| --- | --- | --- |
| `CapsLock` + `I` | 上移一行 | 对应 Quicker 引导键 **I**（Up） |
| `CapsLock` + `J` | 左移（切换分类） | 对应 **J**（Left） |
| `CapsLock` + `K` | 下移一行 | 对应 **K**（Down） |
| `CapsLock` + `L` | 右移（切换分类） | 对应 **L**（Right） |
| `CapsLock` + `O` | 删除搜索字符 | 等同 `Backspace` |
| `CapsLock` + `Q` | 关闭窗口 | 等同当前宿主的 `Esc` |

**触发方式（须同时满足）：**

1. 剪贴板窗口**可见**，且处于**无焦点模式**（未用 `Ctrl+F` 进入正常焦点）。
2. **完整列表接管**：显式唤起或点击窗口内部后参与；外点后仅保留普通数字与 Esc，文字输入或编辑会退出数字接管。仅移回指针、悬停或 Fold 展开不会恢复，须再次点击内部或显式唤起。
3. **CapsLock 引导有效**：**按住 CapsLock** 再按 `I` / `J` / `K` / `L` / `O` / `Q`。窗口显示或键盘钩子就绪时会**同步 CapsLock 物理按键状态**——若 Quicker 用 **`CapsLock+1`**（等）打开且 CapsLock 仍按住，扩展热键会立即生效；若打开时已松开，需在窗口内**再按一次 CapsLock** 后再按导航字母。

松开 CapsLock 后，再按 `i` / `j` / `k` / `l` 会进入**搜索**，不再移动列表。

**与 Quicker 配合：**

- 推荐 **`CapsLock+1`**（或你的打开动作）时**保持按住 CapsLock**，窗口出现后直接按 `I/J/K/L` 导航。
- 若用 **Ctrl+反引号** 等全局热键打开：窗口显示后在窗口内按住 CapsLock 再按导航字母；前台应用可继续保持输入焦点。

**限制与排错：**

- 用过 **`Ctrl+F`** 进入搜索 / 输入法后，无焦点钩子会暂停，扩展热键暂不可用；**关闭窗口再打开**即可恢复。
- 窗口刚弹出时若按键无反应，稍等片刻或再按一次 CapsLock 引导。
- 若完全无反应，请确认 ClipHost 在运行，且窗口未被最小化或完全遮挡。

### 搜索

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl` + `F` | 聚焦顶部搜索框并进入正常焦点（可用输入法） |
| 可打印字符（字母、数字等） | 无焦点模式下由宿主写入搜索；**窗口已激活**且焦点在列表时直接追加到搜索；`Space` 保留给列表多选 |
| 搜索框内 `Enter` | 与列表相同：粘贴当前选中 / 高亮项 |

### 列表导航与选择

| 快捷键 | 作用 |
| --- | --- |
| `↑` / `↓` | 移动高亮行 |
| `←` / `→` | 切换顶部分类标签（全部、文字、图片等） |
| `Shift` + `↑` / `↓` | 从锚点行连选到目标行 |
| `Home` / `End` | 跳到首条 / 末条 |
| `Shift` + `Home` / `End` | 从锚点连选到首条 / 末条 |
| `Space` | 从当前选中块**向下**扩展一行连续多选 |
| `Ctrl` / `⌘` + `Space` | WebView：切换当前高亮行的选中状态；GPUI 暂未支持 |
| `Ctrl` + `A` | 全选历史当前搜索／筛选下已经加载的条目（含屏外行），不主动加载后续分页；输入框内只全选文本 |
| `Ctrl` + `C` / `Ctrl` + `P` | GPUI 历史：复制选中项 / 切换置顶，普通列表焦点与无焦点完整接管均可用；搜索框不触发列表操作 |
| `A` / `B` / `C` | WebView 多选时：顺序粘贴 / 逆序粘贴 / 取消选择（窗口已激活）；GPUI 暂未支持这些按键 |
| `M` | WebView：打开选中项菜单（窗口已激活）；GPUI 请右键条目 |

GPUI 无焦点列表的 Ctrl+A / C / P 只在有效的完整列表接管中处理，不带额外 Shift / Alt / Win；长按只执行一次。点击外部后的数字接管阶段及接管退出后，组合键归外部应用。全选后新增的分页条目不会自动加入选择，再按 Ctrl+A 才会包含它们；收藏树尚未新增全选。

## 鼠标操作

| 操作 | 作用 |
| --- | --- |
| 单击行 | 选中；是否立刻粘贴见下表「粘贴触发方式」 |
| 双击行 | 在「单击复制，双击粘贴」「双击粘贴」模式下执行粘贴 |
| `Shift` + 单击 | 从锚点连选 |
| `Ctrl` / `⌘` + 单击 | 多选增减一行 |
| 右键行 | 拆分、定位文件、置顶、收藏、删除等（随类型与多选变化） |
| 右键列表空白 | 回到列表顶部 |
| 行尾图标 | 单独点击粘贴 / 置顶 / 收藏 / 删除，不触发行选中 |
| 多选操作 | GPUI 使用右键菜单顺序／逆序粘贴；WebView 另有多选浮动条 A/B/C；`Enter` 按选择顺序粘贴 |

## 粘贴触发方式

底部工具栏或 **设置 → 剪贴板 → 粘贴** 中切换，会保存到配置。

| 模式 | 单击 | 双击 |
| --- | --- | --- |
| 单击粘贴 | 选中并粘贴 | — |
| 单击复制，双击粘贴 | 选中（复制到剪贴板） | 粘贴 |
| 双击粘贴 | 仅选中 | 粘贴 |

## 界面与常用功能

| 区域 | 功能 |
| --- | --- |
| 顶部 | 搜索、类型分类、筛选、来源进程筛选 |
| 列表 | 剪贴历史；可滚动或「加载更多」 |
| 底部 | 粘贴触发方式、添加文本、清空、回到开头、「只看置顶」 |
| 添加文本 | 写入历史；可勾选「每行一条」拆分多行 |
| 清空 | 经确认清除全部非置顶历史，不受当前筛选与分页限制；保留置顶项，可撤销 |

## 超级菜单与贴顶晾衣绳

超级菜单的六分类切换栏紧贴菜单上方，本次打开内切换分类或打开文件浏览栏时保持位置，各分类内容顶边对齐。栏尾齿轮打开当前分类和通用设置，右键分类可直接打开对应设置，栏内滚轮循环切换分类。

**设置 → 超级菜单 → 文件菜单 → 贴顶晾衣绳** 默认关闭。开启后，指针在屏幕顶边停留先露出可穿透点击的细绳，随后展开文件标签，默认共约 0.2 秒，可用「展开延迟（毫秒）」调整；全屏程序在前台时停用并隐藏纸片。它与超级菜单「文件」分类并存，共用自定义目录。

- 悬停标签打开纸片，在纸片内进入下一级或返回；夹子可固定纸片，绳子收起后仍可查看，最多固定 3 张。
- 单击条目沿用文件菜单的定位、转到或打开规则，目标取展开时的前台窗口；`Ctrl` + 单击保持展开。离开绳子和纸片约 0.3 秒或单击别处收起。
- 自定义标签可拖动排序，拖到取下区域移出列表，6 秒内可撤销；取下不会删除实际文件或目录。已有文件夹可拖上绳，纸片中的文件可复制拖出。

指针位于可见绳子或纸片上时可开始键盘浏览；开始输入文字、切换前台或单击外部后，按键交回目标窗口。绳子和纸片都隐藏时不接管以下按键。

| 按键 | 作用 |
| --- | --- |
| 标签上的 `←` / `→`、`Home` / `End` | 切换标签，或跳到首个 / 末个标签 |
| 标签上的 `↓` | 进入纸片 |
| 纸片内的 `↑` / `↓`、`Home` / `End` | 选择条目，或跳到首项 / 末项 |
| 纸片内的 `→` / `←` | 进入下级 / 返回 |
| `Enter` / `Ctrl` + `Enter` | 执行条目 / 执行并保持展开 |
| `Space` | 固定或松开纸片 |
| 自定义根标签上的 `Delete` / `Backspace` | 取下标签 |
| `Ctrl` + `Z` | 在 6 秒撤销期限内恢复刚取下的标签 |
| `Esc` | 逐层返回或收起；拖动标签时取消当前拖动 |

## 外观主题

在 **设置 → 全局 → 外观** 中配置（ClipHost 与 legacy 0.8 共用同一套配置语义）：

| 选项 | 说明 |
| --- | --- |
| 界面主题 | **跟随系统** / **浅色** / **深色** / **自定义** |
| 背景色、前景色 | 仅在「自定义」下由你指定；修改后会自动切到自定义 |
| 窗口背景图 | ClipHost 剪贴板窗口支持背景图，可配合「背景混合比例」「背景毛玻璃」（legacy WPF 仍用背景色） |

自定义模式下，配色会按背景/前景推导列表高亮、边框与强调色。

<Note title="无法使用？">
列表一直空白或快捷键无反应时，请确认 ClipHost 已启动（系统托盘有图标）。启动失败时可运行程序目录中的 `Start-ClipHostDiagnostics.cmd` 收集诊断。
</Note>
